# B3 — Generic Compose design-system components

## What it is
Reusable primitives: buttons, typography, spacing tokens, theme layers shared across features/modules.

## Why JDs care
Design-system work signals senior UI ownership and consistency at scale (Booksy ATS lines).

## Honest closes
- **OWN:** One bullet naming scope (tokens, components, migration path) under correct employer.
- **SIDE:** Public mini design-system repo—honestly scoped.
- **SKIP:** If each screen was bespoke without shared layer—do not invent a “system.”

## Interview bite
How you version breaking API changes for UI components across teams.

- Write down **three failure modes** (permissions, background, data integrity, or device variance) you could explain without notes.
