# A22 — React / Redux / JS (ES6+)

## What it is
Web front-end stack often adjacent to RN or full-stack mobile leads.

## Why JDs care
Some mobile-lead JDs still test JS architecture literacy.

## Honest closes
- **OWN:** Production web or RN modules with Redux-like state.
- **SIDE:** Small SPA + state management tutorial tier—honestly labeled.
- **SKIP:** Default if Android is core and JD allows.

## Interview bite
State normalization, middleware, and async error handling—only if claimed.
