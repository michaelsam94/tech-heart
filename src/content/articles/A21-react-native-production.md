# A21 — React Native in production

## What it is
JS/React runtime shipped inside mobile apps, native module bridges, metro bundling, release discipline.

## Why JDs care
Jobgether-type leads sometimes want **years** of RN shipping, not Flutter-only.

## Honest closes
- **OWN:** Apps in store with RN architecture you can explain.
- **SIDE:** Side project (already cached) stays honest; do not merge into employer bullets.
- **SKIP:** If Kotlin/Android is the deliberate brand.

## Interview bite
Hermes vs JSC, bridge performance, native crash triage in mixed stacks.

- Reproduce **one minimal vertical slice** in a throwaway repo (build, run, capture logs)—evidence beats keywords.
- Write down **three failure modes** (permissions, background, data integrity, or device variance) you could explain without notes.
